Notificaciones WhatsApp por pedido

Cada cambio de estado de un pedido envía un WhatsApp automático al vendedor y al cliente final, vía Evolution API.

Es el nombre de la conexión WhatsApp en Evolution API (la que escaneaste el QR). Sin este valor, las notificaciones no se pueden enviar y quedan como "fallidas" para reenviar después.

shield_with_heart Anti-bloqueo

Estas son notificaciones transaccionales (cambio de estado), no marketing — son consideradas seguras por WhatsApp. Aún así el sistema añade una pausa de 800 ms entre envíos.

Botón "Mentoría" del menú

Define a qué número de WhatsApp y con qué mensaje redirige el botón "Mentoría" en la barra lateral. Escribe el mensaje tal cual quieres que llegue — el sistema lo codifica automáticamente.

+

Formato internacional sin + ni espacios. Ejemplo Colombia: 573202241463.

Puedes usar *texto* para negrita en WhatsApp, emojis, saltos de línea y caracteres especiales (ñ, tildes). El sistema codifica el mensaje internamente para que llegue exactamente como lo escribes.
